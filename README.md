# سحابتي غير المحدودة (ArabUnlim) — تطبيق تخزين سحابي عربي عبر تيليجرام (Kotlin)

نسخة تجريبية متكاملة لتطبيق أندرويد شبيه بتطبيق **UnLim** مكتوبة بلغة **Kotlin** وواجهة **Jetpack Compose** باللغة العربية بالكامل (`RTL`)، تتيح للمستخدم ربط حسابه في تيليجرام واستخدام محادثة **الرسائل المحفوظة (Saved Messages)** أو قناته الخاصة كمساحة تخزين سحابية غير محدودة ومجانية للأبد.

---

## المميزات المدمجة في هذه النسخة التجريبية
1. **واجهة عربية 100% من اليمين إلى اليسار (`RTL`)** مبنية بأحدث معايير **Material 3** و**Jetpack Compose**.
2. **نظام مجلدات سحابي ذكي**: ينظم الملفات المرفوعة في تيليجرام داخل مجلدات افتراضية (`#صور_الكاميرا`, `#الفيديوهات_العائلية`, `#مكتبة_الصوتيات`, إلخ) مع إمكانية إنشاء مجلدات جديدة.
3. **رفع ملفات حقيقية من الهاتف**: زر رفع عائم يفتح مدير ملفات الهاتف لاختيار أي صورة أو فيديو أو ملف صوتي أو مستند ورفعه كـ `Document` غير مضغوط للحفاظ على الجودة الأصلية.
4. **مشغل صوتيات ومعرض وسائط مدمج**: لتشغيل الملفات الصوتية واستعراض الصور والفيديوهات.
5. **دعم وضعين للربط السحابي**:
   - **وضع التجربة الفورية (Sandbox Mode)**: يعمل مباشرة فور تثبيت الـ APK لتجربة جميع الشاشات والمجلدات ورفع الملفات.
   - **وضع الرفع السحابي الفعلي لتليجرام**: من أيقونة السحابة أعلى التطبيق (أو تبويب الإعدادات)، أدخل `API ID / API Hash` أو `Bot Token` و`Chat ID` ليرفع التطبيق الملفات فعلياً من هاتفك إلى حسابك على تيليجرام عبر مكتبة `OkHttp3` وجسر `TdlibClientBridge`.

---

## طريقة تحويل المشروع إلى ملف APK عبر منصة Klencod IDE و GitHub Actions

المشروع مجهز مسبقاً بملف البناء التلقائي `.github/workflows/android-build.yml` المتوافق مع **GitHub Actions** ومع تطبيق **Klencod IDE**:

1. **فك الضغط أو الاستيراد في Klencod IDE**:
   - افتح تطبيق **Klencod IDE** على هاتفك واستورد ملف المشروع أو ارفعه إلى مستودع جديد (Repository) على حسابك في **GitHub**.
2. **تشغيل البناء التلقائي (GitHub Actions)**:
   - بمجرد رفع الملفات إلى مستودع GitHub (على الفرع `main` أو `master`)، سيبدأ مسار العمل **Build ArabUnlim APK** تلقائياً في تبويب **Actions**.
   - يمكنك أيضاً تشغيله يدوياً بالضغط على **Actions** ثم **Build ArabUnlim APK** ثم **Run workflow**.
3. **تنزيل ملف الـ APK الجاهز للتثبيت**:
   - بعد انتهاء البناء (يستغرق حوالي دقيقتين إلى 3 دقائق)، ادخل على عملية البناء الناجحة وستجد في قسم **Artifacts** ملفاً باسم **`ArabUnlim-Debug-APK`** يحتوي على `app-debug.apk` الجاهز للتثبيت على هاتفك مباشرة.

---

## هيكل المشروع
- `.github/workflows/android-build.yml`: ملف البناء السحابي التلقائي لاستخراج الـ APK عبر GitHub.
- `app/build.gradle.kts`: إعدادات Kotlin 1.9.24 و Jetpack Compose و OkHttp3 و WorkManager.
- `app/src/main/java/com/arabunlim/cloud/MainActivity.kt`: الشاشات العربية الكاملة (الرئيسية، المجلدات، الوسائط والصوتيات، الإعدادات، وتسجيل الدخول).
- `app/src/main/java/com/arabunlim/cloud/network/TelegramCloudClient.kt`: محرك رفع الملفات الفعلي إلى سحابة تيليجرام.
- `app/src/main/java/com/arabunlim/cloud/network/TdlibClientBridge.kt`: جسر الربط مع مكتبة `TDLib` وتقسيم الملفات الأكبر من 2 جيجابايت.
